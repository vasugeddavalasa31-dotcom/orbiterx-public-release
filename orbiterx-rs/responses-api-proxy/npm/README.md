# @openai/orbiterx-responses-api-proxy

<p align="center"><code>npm i -g @openai/orbiterx-responses-api-proxy</code> to install <code>orbiterx-responses-api-proxy</code></p>

This package distributes the prebuilt [OrbiterX Responses API proxy binary](https://github.com/openai/orbiterx/tree/main/orbiterx-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/orbiterx-responses-api-proxy.js --help
```

Refer to [`orbiterx-rs/responses-api-proxy/README.md`](https://github.com/openai/orbiterx/blob/main/orbiterx-rs/responses-api-proxy/README.md) for detailed documentation.
